**Working on**

- [ZxwDB](https://zxwdb.fiqihbadrian.my.id/) is a visual ERD editor for MySQL and MariaDB; it reads your schema and draws the relationships for you.
- [Soalin](https://soalin.fiqihbadrian.my.id) takes a lecture PDF and turns it into a multiple-choice quiz.
- [IT-Helper](https://ticket.fiqihbadrian.my.id) is a helpdesk for small IT teams — Next.js, Supabase, two Telegram bots, an embeddable widget.

**Smaller things**

- [AI-Content-Forensics](https://aicf.fiqihbadrian.my.id) guesses whether a piece of text was written by a model.
- [Live-Coding-Lab](https://livecoding.fiqihbadrian.my.id) is a browser playground for demos during talks.
- [DrawOverlay](https://drawoverlay.fiqihbadrian.my.id/) lets you draw on top of the screen while explaining something.
- [Markdown-Viewer](https://github.com/fiqihbadrian/Markdown-Viewer) is a macOS app that renders Markdown the way GitHub does.
